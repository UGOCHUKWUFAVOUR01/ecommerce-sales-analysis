# E-commerce Sales Analysis (2021)

## Project Overview
This project analyses a 2021 e-commerce sales dataset to understand sales performance, identify trends and generate useful business insights.

The goal is to turn raw sales data into meaningful information that can support better business decisions.

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Project Files
- `01-Dataset/` – Original e-commerce dataset.
- `02-PowerBI/` – Power BI dashboard file.
- `Project Report/` – PDF report containing dashboard screenshots, key insights and recommendations.

## Project Process
1. Obtained the 2021 e-commerce dataset from Kaggle.
2. Cleaned and prepared the data.
3. Analysed the data to explore sales performance.
4. Created an interactive dashboard using Power BI.
5. Documented key insights and recommendations.

## Dashboard and Findings
See the PDF in the Project Report folder for the dashboard screenshots, insights and recommendations.
